# 经销商临时退款审核规则

适用于 OA 经销商临时退款申请流程（流程 ID `195056`）的专项预审和签字意见。以下口径已按业务规则《临时退款审核》及后续业务确认核对。

## 确定本单取数范围

从冻结的 `dealer_finance_evidence` 读取流程、实际节点、公司、客户及退款明细。公司取申请公司，空白时取支付公司。两者均空时，按客户查询 DMS，其他账务结果按实际查询公司标明范围。退款书所示公司仅作取数线索，公司归属仍待核。

记录各来源的取数时间。归档单区分原审批时点和本轮查询时点。取数有缺口时写具体缺口及影响。未阅转发提交批注，正常流程仅在 RPA 预审节点提交意见。

## 审核条件

| 审核项 | 按本单证据判断 |
| --- | --- |
| 退款资格 | 临时退款适用于代配送或代结算客户。F26 无代结算客户。代配送查 DMS KA 代配合同，复核公司、客户、签署完成状态和有效期。未查到适用合同或签署、有效期未能证实时，写“代配资格待核”。1+N 不适用临时退款。 |
| 退款金额 | 列 BI 客账余额或预付款、SAP 占单和下单剩余。按同公司、客户、币种和对应时点的 SAP 下单剩余比较申请金额，写明在余额内、超出或等额。超出余额时，金额条件不符合。额度按 SAP ZSD025 的业务口径取得。多明细按同一余额组列逐笔和合计，禁止跨客户合并额度。只有旧数据时，标明日期，当前余额待核。BI `remain_balance` 不替代 SAP 下单剩余。 |
| 三方融资 | 查 BI 近 6 个月融资，记录起止日期及覆盖情况。有三方融资不允许退款。汇总为 0 可列示，覆盖不完整时三方融资条件仍待核。 |
| BI 必报项目 | 逐单写出预提余额、特别总账科目余额、免投冰柜结果。多科目按实际明细列示，重复的客户余额只列一次。BI 冰柜空值按明确适用于本单的业务确认解释，否则待核。 |
| 对账单 | 直接从 DMS 核客户与审核日上一个自然月，签署完成即可。已确认归属其他公司的对账单不能用作本单证据。查询不到或签署状态未完成时列出实际结果。 |
| 退款申请书 | 单独列一项。直接从 DMS 核所属公司、客户名称、是否签署完成、退款金额和大写金额。逐条对应 OA 明细，核对同口径 BI 金额并列差异。只有旧书或多份同额且无法确认对应关系时，关联待核。 |
| 收款账户 | 退款书载有账号，且户名核实为客户名称或法定代表人，或者户名和账号匹配同公司 DMS 报备，即符合账户要求。客户名称或法定代表人已核实的账户无需报备。法人以 SAP ZMD001 核验，DMS 户名比对可供查证。已查明三类依据均不成立时列账户不合格。账号、身份或报备证据不足时列待核。 |

对账单和退款申请书采用 DMS 的签署完成状态。OA 附件字段是否填值、支付状态均不纳入本流程审核。

## 退款申请书结果

| 查询结果 | 签字意见 |
| --- | --- |
| 查询成功，范围内 0 份 | ❌ DMS 未查到本单公司及客户对应的退款申请书。签署状态、金额和收款账户待核。 |
| 有记录，未找到与明细对应的已签申请书 | ❌ 写明所缺依据，例如未签署、金额不符或关联待核。 |
| 查询失败或身份、范围未核实 | ❌ 写明读取失败或范围待核，保留具体原因。 |
| 已签且身份、明细金额与大写均核对通过 | ✅ 写明已核事项。BI 差异和账户核对结果分别列出。 |

## 待确认和取数缺口

- 业务仍待确认的口径包括 KA 有效期的核对时点、BI 金额比对字段、等额及部分退款的允许条件、旧退款申请书复用和同额多份的选取规则、无单独业务确认时的临时退款免投冰柜空值口径。数值比较可先做，涉及这些口径的最终判断保留待核。
- 首先读取本轮 OA、DMS、BI 及 SAP 业务额度证据。六个月融资覆盖、SAP ZMD001 法人核验及其他适用依据缺失时，逐项保留待核。

## 签字意见

逐单列单号、申请金额、在途或归档、账务取数时点。写出退款资格、金额与下单剩余的比较、六个月融资、BI 必报项目、对账单、退款申请书及账户结果。用 ✅ 标已核符合的项目，用 ❌ 标异常或待核并写明原因。退款申请书单列，余额比较同时写逐笔和合计（适用于多明细）。任何必审条件待核时，签字意见只确认已核项目。
