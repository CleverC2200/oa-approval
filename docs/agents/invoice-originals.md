# 关联发票原件读取

当前已核实的发票云资料响应在同一记录中提供有效 PDF 文件、`modify_info.pdf/furl` 与 `oa.doc_id/img_id`。采集器仅支持唯一有效 PDF、两个原件引用均指向该云文件、明确返回记录身份及票号的映射。云文件 ID 与 OA 主文件 ID 分属两个来源，不能互换。其他格式、多个 PDF 或缺少映射时保留未读，不推测下载接口。

下载前重新读取当前流程及关联票资料，核对请求身份、六类流程配置、关联票 ID/票号和完整原件映射，再以当前 Cookie 核验账号及原生文档的主文件。缓存命中也执行该核验。普通流程附件共享表没有这类原件时，被拒绝后的初始化沿同一可信关联重新解析文档；仍保留 `basicInfo` 初始化前后主文件核对、`isrequest=1`/当前 `requestid`、同 Cookie 同 URL 单次重试。原生访问可能触发 OA 正常共享初始化，不修改权限配置或发起审批。

原件沿普通下载、PDF 全页准备及冻结资源链进入材料。正文覆盖状态以[观察合同](../../.agents/skills/oa-finance-preaudit/references/observation-contract.md)为准；明确绑定原件的下载或准备失败继续停止当前取材。历史冻结材料和意见不改写。

2026-10-18 的原生页面及[发票云前端源码](https://inc.mypiaojia.com/corpInvoice/js/jsapp.1792139559024.js)对照确认，部分关联原件在上述身份及上下文核验通过后，OA 文档下载仍拒绝，而原生发票详情可以下载。该场景使用同一发票云的 `GET https://api.mypiaojia.com/invoiceApi/file/download`，`id` 为唯一有效 PDF 的云文件 ID，`fid` 为当前关联票的云记录 ID，`dataId` 为当前流程的关联票引用，`token` 取现有 OA 发票云令牌入口。真实对照下载的 PDF 与原生页面下载包内原件字节一致。

此路径仅用于已可信绑定的关联发票原件。下载前重新读取当前关联及完整映射，下载后再次核对；仍保留原账号、文档和主文件核验。令牌只存在于当前请求，不写入资源、缓存或错误信息；拒绝重定向，正文限 50 MiB，长度及 PDF 读取失败保持技术失败。普通附件和无可信映射的文件不使用该路径，也不因此修改 OA 权限。
