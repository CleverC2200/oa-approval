# 收尾记录已授权的正常交接

明确授权本轮完成阶段目标并把余单交给后续轮次时，已领取单逐项核清且写入结果已确认后，在收尾记录中表达[正常交接](../../GLOSSARY.md#审核结果)。批次结果照实反映提交、失败和未领取数，接续资格按实际保护条件独立核验。这样主动交接、技术故障和用户暂停都能按真实原因回报，即使它们都有剩余待办。

验收沿用公开关闭、状态和接续入口，覆盖阶段验收后授权交接、真实技术失败后保留接续、还有未知提交和用户暂停。新轮重新排队后，旧轮仍能按原关闭事实回查。 [Issue #129](https://github.com/CleverC2200/oa-approval/issues/129)
