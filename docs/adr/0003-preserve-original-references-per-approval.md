# 逐单独立取证并保留原件出处

每单独立取得原件及其来源证据。同一可信资源保留经核实的各个[原件出处](../../GLOSSARY.md#材料)，归属冲突按现有校验处理。不同资源分别保留原件证据，即使同名或内容一致。同单内容经确认完全一致时，可以复用读取结果，保留每份原件与其出处的对应关系。[Issue #132](https://github.com/CleverC2200/oa-approval/issues/132)

必需证据准备完成后，账本才能确认[材料就绪](../../GLOSSARY.md#材料)。原件缺失时保留已取得的材料和失败证据，隔离本单。共享来源恢复按已取得的来源证据独立记录。[Issue #130](https://github.com/CleverC2200/oa-approval/issues/130) · [ADR-0001](0001-scope-pauses-to-the-unavailable-source.md)
