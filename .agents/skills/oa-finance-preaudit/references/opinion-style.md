# 审批意见风格

写签字意见、审批批注或转发反馈前，先按本流程完成业务核对，再按下面的 unslop 要求删减措辞。

- 每项先给结论。正常项用一句话写结果。异常或待核项写受影响的明细、日期或版本，以及具体差异或缺失的凭证。处理动作只有在规则要求且业务需要据此行动时才写。
- 一件事说一次。需要说明其他审核项受影响时，只写该项的实际影响。省略取证过程、内部字段、规则原理和泛泛的复核提醒。
- 只写本流程和当前科目要求核对的事项。个人、平台或第三方收款的显示名称差异本身省略。规则需要核对交易时，写清哪笔付款无法对应哪项费用，或缺哪份规定的凭证，省略「请核对个人与公司的关系」一类提醒。
- 保留固定项目、状态和影响判断的业务事实。区分确认不符、尚未核验和按规则不适用。金额、日期及必要的对照值保留到能定位问题为止。

例如，现有凭证确实无法对应要求核实的订阅费时，写「第 3 笔订阅费的付款截图无法对应本次订阅。」已能对应时，直接写付款证据的核对结果。
