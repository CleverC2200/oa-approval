# 关户结果合同

每单在本次私有运行目录保存独立`签字意见.txt`和`核对记录.md`，多单可另汇总可复制文本。申请ID、流程编号、公司及客户编码在标题定位，不在每句重复。

## 签字意见顺序

1. 预付款、预提、特别总账、占单、SAP下单剩余、免投冰柜、发货权限。
2. 近6个月融资、最后发货后补贴；仅有BI汇总时写“BI为0元”等来源限定，已知覆盖缺口标待核。
3. 有余额退款单的对账签署月份和退款书金额/大写/账户；无余额单说明不退款、对账非强制。已结转或退款记账一句说明当前去向。
4. 全部具体异常、关键待核，保留金额/状态及必要处理，同一缺口只写一次。

| 标识 | 含义 |
| --- | --- |
| ✅ | 所列项目核对正常或按规则不适用，正常项合并，关键金额保留。 |
| ❗ | 异常或关键待核，分别写“仍有……”“未锁……”或“待核……”，不把未知写成已经发生问题。 |

适用关键项全已核实正常时，可写`✅ 关户审核无异常。`并保留关键金额及材料结论。有待核时✅只修饰已核项目，不写整单全部审核无误、可退款或已批准；图标不是OA提交回执。

零值合并写“预提、特别总账、占单均0元”；一项非零则从正常句去掉该项，另列准确性质和金额，不自行净额冲抵。

意见用业务语言，接口、字段名、分页、算法和运行目录另存。无冰柜直接写“无免投冰柜”，确认范围和来源另存；技术字段映射不被改写成未证实的账面余额异常。

## 合成格式示例

以下金额为合成例，不用于实际取数或豁免。

### 无余额，覆盖完整

```text
✅ 预付款、预提、特别总账、占单、SAP下单剩余均0元；无免投冰柜；权限已锁。不退款，对账单非强制。
✅ 近6个月无三方融资，最后发货后无新增补贴。
```

### 有余额，存在异常和覆盖缺口

```text
✅ 预付款18,500.00元，BI与SAP账面余额一致；SAP下单剩余18,500.00元；特别总账、占单均0元；无免投冰柜。8月对账已签；退款书金额、大写及报备账户一致。
融资及发货后补贴：BI均0元。❗ 期初导入前历史覆盖待核。
❗ 预提借方余额1,200.00元仍在；发货权限未锁。
```

### 新单冰柜数量缺失

```text
✅ 预付款、预提、特别总账、占单、SAP下单剩余均0元；权限已锁。无余额关户不涉及退款，对账单非强制。
✅ 近6个月无三方融资，最后发货后无新增补贴。
❗ 当前免投冰柜数量待核。
```

示例中的“无融资/无新增补贴”只用于覆盖依据完整；仅有BI汇总0时保留来源限定，不能照抄成覆盖完成。

## 核对记录

供后续Agent回查，不复制进业务意见：

- 身份及范围：申请ID、流程编号、公司/客户、分支、金额、实际节点、审核截止日和本次授权。
- 规则及补充：业务文档版本、确认客户/日期/范围；原始空值与确认依据分别保存。
- 事实表：所有适用审核项的原值、单位、来源文件/响应位置、取数时点、正常/异常/待核/不适用状态及原因。
- 差异：同义字段两侧金额及时点、原科目/后续凭证/冲销链、读取完整性、复算组件和实际失败；完整材料及请求响应另存给路径。
- 输出：意见绝对路径和实际提交状态。只生成意见写未提交，已提交须有真实回执和必要回查。

正常结论能回到来源，待核指向具体缺口和下一项取证。复用前次结果说明来源及时点，不装成本轮实时调用。
